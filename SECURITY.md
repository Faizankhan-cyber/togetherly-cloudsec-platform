# Security Policy

## Scope

This repository contains an educational cloud security engineering project. Security testing must be limited to the project owner's code, explicitly authorised Togetherly environments, and disposable lab resources.

## Reporting a vulnerability

Please do not publish credentials, tokens, personal information, private evidence, or exploitable details in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use that channel. Otherwise, contact the repository owner privately through GitHub before sharing sensitive details.

## Safe testing rules

- Obtain permission before testing any system.
- Use local, staging, or disposable lab environments wherever possible.
- Do not access, modify, or disclose another person's data.
- Do not commit secrets, private keys, service-role credentials, or sensitive Terraform state.
- Remove temporary cloud resources after testing and verify their deletion.

## Project status

Security controls and findings are documented as they are verified. The presence of a tool or planned control in the roadmap does not mean it has been deployed or validated.
